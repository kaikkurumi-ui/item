## 第10关 多数据源接口伪代码

```java
@RestController
@RequestMapping("/home")
@Slf4j
@RequiredArgsConstructor
public class HomeController {


    private final GoodsService goodsService;
    private final CategoryService categoryService;
    private final ChannelService channelService;
    private final ActiviryService activiryService;
    private final ContentService contentService;
    @RequestMapping("/data")
    public Map<String,List<Object>> home(){
        // 1. 定义所有任务
        CompletableFuture<List<HomeData>> homeFuture =
                CompletableFuture.supplyAsync(() -> goodsService.getHomeData());
        CompletableFuture<List<CategoryData>> categoryFuture =
                CompletableFuture.supplyAsync(() -> categoryService.getLevelOneCategory());
        CompletableFuture<List<ChannelData>> channelFuture =
                CompletableFuture.supplyAsync(() -> channelService.getHomeChannel());
        CompletableFuture<List<ActivityData>> activityFuture =
                CompletableFuture.supplyAsync(() -> activityService.getHomeActivity());
        CompletableFuture<List<ContentData>> contentFuture =
                CompletableFuture.supplyAsync(() -> contentService.getRecommendContent());

        // 2. 等待所有完成（带超时，防止无限等待）
        CompletableFuture<Void> allFutures = CompletableFuture.allOf(
                homeFuture, categoryFuture, channelFuture, activityFuture, contentFuture
        );
        try {
            allFutures.get(5, TimeUnit.SECONDS); // 超时5秒
        } catch (Exception e) {
            log.error("获取首页数据超时或失败", e);
            return getFallbackMap(); // 降级数据
        }

        // 3. 组装结果（此时所有任务已完成）
        Map<String, List<Object>> result = new HashMap<>();
        result.put("homeData", homeFuture.join());
        result.put("category", categoryFuture.join());
        result.put("channel", channelFuture.join());
        result.put("activity", activityFuture.join());
        result.put("content", contentFuture.join());

        return result;
    }
}
```
